# Privacy Policy

**Last updated:** May 6, 2026

## Overview

This application ("SpaceX IPO Bot") is a personal notification tool that monitors publicly available online news sources and sends SMS alerts to the owner's phone number regarding SpaceX IPO-related news.

## Data Collection

- This application does **not** collect, store, or share any personal data from third parties.
- The only phone number used is the owner's personal number for the sole purpose of receiving notifications.
- No user accounts, sign-ups, or registrations are involved.

## Data Usage

- No user data is sold, rented, or shared with any third parties.
- The application monitors publicly available sources (Google News, SEC EDGAR, Reddit) and sends notifications via SMS using the Twilio API.
- Message content consists solely of publicly available news article titles and URLs.

## Data Storage

- No personal data is stored beyond the owner's phone number in a local configuration file.
- A list of previously seen article URLs is stored locally to prevent duplicate notifications. This data contains no personal information.

## Third-Party Services

This application uses:
- **Twilio** — for sending SMS messages. Twilio's privacy policy can be found at https://www.twilio.com/legal/privacy

## Consent

The owner of this application has explicitly opted in to receive SMS notifications by configuring their own phone number.
